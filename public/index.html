API log

How it works. The browser sends each step to a Cloudflare Pages Function that adds the Clocked key server-side and forwards the request to clocked.rezolve.ai/clocked/<endpoint> with a fresh Idempotency-Key. Offsets in every response are Unicode code points into the text that was sent, so highlights land on the exact characters Clocked read.
